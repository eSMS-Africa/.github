# eSMS Africa

**SMS, OTP and messaging APIs for all 54 African countries.**

[esmsafrica.io](https://esmsafrica.io) provides bulk SMS, an SMS API, managed OTP verification, two-way SMS, SMPP 3.4 connectivity, transactional email and short links for businesses and developers across Africa. Direct routes to the main networks, delivery reports on every message, pay as you go from USD 20 with no setup fee.

[Website](https://esmsafrica.io) - [Documentation](https://docs.esmsafrica.io) - [Pricing](https://esmsafrica.io/pricing) - [Create an account](https://auth.esmsafrica.io/register?service=sms)

---

### Products

| Product | What it does | Learn more |
|---------|--------------|------------|
| Bulk SMS | Campaigns, contacts, CSV/Excel imports, scheduling | [esmsafrica.io/bulk-sms](https://esmsafrica.io/bulk-sms) |
| SMS API | REST API with delivery reports and webhooks | [esmsafrica.io/sms-api](https://esmsafrica.io/sms-api) |
| eSMS Verify | Managed OTP: send and check codes in two calls | [esmsafrica.io/verify](https://esmsafrica.io/verify) |
| Two-way SMS | Short codes and keywords for inbound messages | [esmsafrica.io/two-way-sms](https://esmsafrica.io/two-way-sms) |
| SMPP 3.4 | Direct binds for aggregators and high-volume senders | [esmsafrica.io/smpp](https://esmsafrica.io/smpp) |
| eSMS Mail | Transactional email with DKIM, webhooks and SMTP relay | [esmsafrica.io/mail](https://esmsafrica.io/mail) |
| eSMS Links | Branded short links and QR codes | [esmsafrica.io/links](https://esmsafrica.io/links) |
| eSMS Chat | AI and human customer support chat | [esmsafrica.io/chat](https://esmsafrica.io/chat) |

### Official SDKs

| Language | Install | Repository |
|----------|---------|------------|
| Node.js / TypeScript | `npm install esms-sms` | [esms-sdk-node](https://github.com/eSMS-Africa/esms-sdk-node) |
| Python | `pip install esms-sms` | [esms-sdk-python](https://github.com/eSMS-Africa/esms-sdk-python) |
| PHP | `composer require esmsafrica/sms` | [esms-sdk-php](https://github.com/eSMS-Africa/esms-sdk-php) |
| Go | `go get github.com/eSMS-Africa/esms-go` | [esms-go](https://github.com/eSMS-Africa/esms-go) |

SDK guide: [docs.esmsafrica.io/docs/sdks](https://docs.esmsafrica.io/docs/sdks) - Sandbox: [docs.esmsafrica.io/docs/sms/sandbox](https://docs.esmsafrica.io/docs/sms/sandbox)
